顧客預約頁改版 — 可上線型 HTML

照 Figma「2026 May. 顧客預約頁改版」定稿實作的真 DOM 頁面。三種預約模式各一個檔案，接上 API 即可運作。

① 基本人數預約

只選人數、日期與時段。餐廳訂位的預設模式。

開啟 →

② 服務項目預約

先選預約項目，再選人數、日期與時段。

開啟 →

③ 階層項目預約

選父層項目 → 選子項目，再選人數、日期與時段。

開啟 →

逐段檢視（1-1 ~ 1-7）

同一份程式碼，用 window.SECTION 把畫面快轉到該段落起點，方便和工程師手刻的檔案逐段比對。

段落

預約狀態（用「查詢預約」進入）

手機號碼一律 0987654321，代碼決定看到哪一種狀態。

空狀態與訂金規則（網址參數）

加在任一模式檔後面即可，例如 1-基本人數預約.html?state=closed。

Demo 劇本

· 時段 18:30 第一次送出會回「預約已滿」popup，其他時段直接成功
· 12:00 / 12:30 / 18:00 / 19:00 為不可選時段
· 表單空白直接送出可看驗證錯誤樣式
· 手機填 0900000000 會觸發黑名單（定稿「預約已滿 B」）
· 待付款／待綁卡按「前往付款」會導去模擬金流頁，付完導回本頁更新狀態
· 頁首 EN 會連店家內容（公告、須知、項目）一起換成英文
